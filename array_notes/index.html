📝 About Arrays

Arrays are mutable objects in JavaScript used to store multiple values inside a single variable.

Unlike strings, arrays can be modified after they are created. You can add, remove, replace, or reorder their elements.

This project demonstrates the most commonly used JavaScript array methods. All outputs can be viewed in the browser console.

  3. Go to the Console tab.
